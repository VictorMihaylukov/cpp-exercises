# 0
Создать консольный C++-проект с файлами: main.cpp, math.cpp, math.h

Выполнить следующее:

1. В `Math.h`:
    
    - добавить защиту header через `#pragma once`
    - объявить функции:
    
    ```cpp
    int Add(int a, int b);
    int Subtract(int a, int b);
    int Multiply(int a, int b);
    int Divide(int a, int b);
    ```
    
2. В `Math.cpp`:
    
    - подключить `Math.h`;
    - реализовать все четыре функции;
    - для `Divide` пока достаточно обычного целочисленного деления, обработку деления на ноль сейчас делать не нужно.

3. В `main.cpp`:
    
    - подключить `Math.h`;
    - вызвать все четыре функции;
    - вывести результаты в консоль;
    - в `main.cpp` **не должно быть definitions** этих математических функций.
    
5. После этого **по очереди** намеренно создать три ошибки:
    
    - **Compile error** — создать ошибку именно такую, которую должен обнаружить компилятор.
    - **Unresolved external symbol** — declaration должен остаться доступен `main.cpp`, но linker не должен найти definition одной из вызываемых функций.
    - **Multiple definition** — добиться того, чтобы одна обычная `non-inline` функция имела несколько definitions в разных translation units.

# 1.3
Создай консольную программу, в которой есть:

```cpp
enum class BufferUsage : uint32_t
{
    Vertex   = 1 << 0,
    Index    = 1 << 1,
    Constant = 1 << 2
};
```

Требования:

1. Создай переменную `usage`, в которой одновременно установлены флаги `Vertex` и `Index`.
2. Реализуй функцию:

```cpp
bool HasFlag(uint32_t usage, BufferUsage flag);
```

Она должна возвращать `true`, если переданный флаг присутствует в `usage`, иначе `false`.

3. С помощью `HasFlag` проверь наличие всех трёх флагов:
    
    - `Vertex`
    - `Index`
    - `Constant`
4. Выведи результат примерно так:
    
```cpp
Vertex: true
Index: true
Constant: false
```

5. Дополнительно создай второй набор:

```cpp
Vertex + Constant
```
и тоже проверь все три флага.

# 2.3 
Возьми такую структуру:
```cpp
struct Vertex
{
    float x;
    float y;
    float z;
};
```

Тебе нужно реализовать:
```cpp
void ByValue(Vertex v);
void ByReference(Vertex& v);
void ByConstReference(const Vertex& v);
void ByPointer(Vertex* v);
```

Требования простые:
- ByValue - измени x на 10;
- ByReference - измени x на 20;
- ByConstReference - просто выведи x;
- ByPointer - измени x на 30, но учти возможность nullptr.

Затем в main() создай:
`Vertex vertex{1.0f, 2.0f, 3.0f};`

и последовательно вызови все четыре функции. После каждого вызова выводи vertex.x, чтобы увидеть результат.
Ещё добавь вывод адреса исходного объекта:
`std::cout << &vertex << '\n';`

А внутри каждой функции попробуй вывести адрес объекта, с которым она работает.
